# Glossary

## Mentor
- Mentor é o usuário responsável por conduzir mentorias, criar avaliações iniciais, estruturar planos de aprendizado, acompanhar tarefas e fornecer feedback ao learner.

## Learner
- Learner é o usuário que busca orientação técnica, solicita mentorias, responde avaliações iniciais, segue planos de aprendizado e executa tarefas.

## Stack
- Stack é uma tecnologia, linguagem, framework, ferramenta ou área técnica usada para conectar learners a mentors com especialidade relevante.

## Mentorship Request
- Mentorship Request é o pedido enviado por um learner para iniciar uma mentoria com um mentor específico, contendo a stack desejada e o objetivo final do learner.

## Mentorship
- Mentorship é o relacionamento ativo entre mentor e learner após o aceite de um mentorship request.

## Initial Assessment
- Initial Assessment é o formulário inicial criado pelo mentor e enviado ao learner para diagnosticar seu nível atual, contexto, lacunas de conhecimento e objetivos.

## Learning Plan
- Learning Plan é o plano de aprendizado criado pelo mentor com etapas, tarefas e direcionamento para alcançar o objetivo do learner.

## Task
- Task é uma atividade definida dentro de um learning plan que o learner deve executar e submeter para avaliação do mentor.

## Feedback
- Feedback é a avaliação qualitativa enviada pelo mentor sobre uma task, progresso ou desempenho do learner.

## Rating
- Rating é a avaliação feita pelo learner ao final da mentorship, usada para reputação e ranqueamento de mentors.

## Leveling Assessment 
- Pesquisa de nivelamento enviada ao learner, primeira tarefa de uma mentoria.
